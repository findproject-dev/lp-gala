# GALACODE Project Rules

## Tech Stack & Package Manager
- **Package Manager:** WAJIB MENGGUNAKAN `bun`. JANGAN PERNAH MENGGUNAKAN `npm` ATAU `yarn` SAMA SEKALI. (STRICT RULE)
- **Auto-Cleanup:** If `package-lock.json` or `node_modules` (created by npm) exist, delete them immediately.
- **Framework:** Astro (Static Site Generation).
- **Styling:** Tailwind CSS.

## Development Workflow
- **Install:** `bun install` (JANGAN PERNAH GUNAKAN `npm install`)
- **Dev:** `bun run dev` (JANGAN PERNAH GUNAKAN `npm run dev`)
- **Build:** `bun run build` (JANGAN PERNAH GUNAKAN `npm run build`)

## Design Principles
- **Aesthetic:** Premium, Modern, Minimalist.
- **Colors:** Warm Off White (#F8F6F2), Silver (#C0C6CC), Dark Charcoal (#2B2F36).
- **Performance:** High Lighthouse scores (95+), Mobile-first, Minimal JS.
